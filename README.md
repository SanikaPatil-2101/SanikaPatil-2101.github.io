## 🚀 Live Interactive Features

1. **Planar Forward Kinematics Simulator**:
   - Real-time trigonometric physics rendering on HTML5 Canvas.
   - Interactive joint sliders ($\theta_1, \theta_2, \theta_3$) and wave animation mode.
   - Live Cartesian Tool Center Point (TCP) coordinate telemetry $(X, Y)$ in millimeters.
2. **Project Filter & Modal Breakdown**:
   - Filterable catalog of featured robotics, IoT, CAD, and enterprise software systems.
   - Detailed specifications modal with hardware ratings, architecture notes, and direct GitHub links.
3. **Responsive Cyber-Engineering Design**:
   - Modern dark glassmorphism theme, ambient glow backdrop, and mobile-responsive layout.

## 🏃 Running Locally

Simply double-click `run-portfolio.bat` or run:

```bash
# Using Python
python -m http.server 3000

# Or open directly in browser
start index.html
```
Then visit `http://localhost:3000`.
